## Что реализовано

### Смены
- Открытие/закрытие смен
- Нумерация по порядку (`shiftNumber`) — виден пробел при удалении
- Типы смен: Сутки, День, Ночь, Управляющий
- Добавление сотрудников в смену с проверкой доступных типов смен
- Автопересчет цепочки смен при изменении операций
- Ограничение на редактирование закрытых смен (3ч для seller, 7д для manager)

### Операции
- Приход / Расход
- Статьи расходов с привязкой к справочникам:
  - Контрагент → Контрагенты
  - Заработная плата → Сотрудники (только seller/manager, без owner)
  - Подрядчик → Подрядчики
  - Хоз. нужды — без связи
  - Прочие выплаты — без связи
  - Инкассация выручки → Сотрудники (только owner/manager)
- Фото к операциям
- Редактирование и удаление операций
- Валидация: нельзя провести расход без заполненного связанного справочника

### Справочники
- Статьи расходов (с возможностью задать linkedRef)
- Контрагенты
- Сотрудники (Имя, Роль, PIN, доступные типы смен)
- Подрядчики
- Формы оплаты
- Типы смен (неудаляемый)
- Возможность создавать пользовательские справочники

### Пользователи и права
- Роли: seller, manager, owner
- seller: открывает свою смену, видит только свои смены
- manager: все смены, справочники, отчеты
- owner: полный доступ
- PIN-коды для входа (проверка уникальности)
- Проверка активности пользователя при входе

### Техническое
- React + Vite + IndexedDB
- PWA: service worker, manifest
- GitHub Pages деплой
- Offline-first (данные в браузере)
